# Comandos Utiles
1. git init
2. git add .  muestra para ver si todo esta bien
3. git reset . regresar el add .
4. git commit -m guarda archivos
5. git checkout -- . revertir cambios anterior commit
6. git log ver quien hizo cambios
7. git commit --amend poder modificar texto commit
8. git checkout -b rama-heroes
9. git branch
10. git checkout master regresar rama master
11. git merge rama-heroes
12. git branch -d rama-heroes borrar rama
13. git push
14. git commit -am para no poner add y commit siempre
